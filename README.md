#🏋️‍♀️ FitLife – Health & Wellness Tracker

**FitLife** is a mobile fitness and wellness app that helps users build healthy habits, track workouts, sleep, hydration, and mood.  
Designed with a simple and modern interface, FitLife motivates users to stay active and maintain a balanced lifestyle.

---

## 🌿 About
FitLife was developed as part of the **Mobile Application Development (IT2010)** module at **SLIIT**.  
It empowers users to monitor daily wellness activities and form consistent healthy habits using an easy-to-navigate Android interface.

---

## 🚀 Features
- 🏃 Track daily **habits** and mark progress  
- 😊 Maintain a **mood journal**  
- 💧 Enable **hydration reminders**  
- 🎯 Set and view **fitness goals**  
- 🛌 Log **sleep and wellness** data  
- 🔐 **Login & Signup** with validation  
- 💾 **SharedPreferences** used for data persistence
